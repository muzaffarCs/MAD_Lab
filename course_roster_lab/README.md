# Course Roster Console App

## Lab 1 — Dart Fundamentals

A simple Dart console application created for Lab 1.

The application demonstrates:

- Dart functions
- `var`, `final`, and `const`
- Basic data types
- `List`, `Set`, and `Map`
- Null safety
- String interpolation and formatting
- Arithmetic and type-checking operators
- Cascade operators
- `if/else`
- `switch`
- Ternary operator
- `for-in`
- `forEach`
- Collection literals with `if` and `for`
